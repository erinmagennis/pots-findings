# Audits

Human-read audit material for the POTS findings packages. Nothing here changes the data; it records what has been
checked and what is still open.

- `fidelity/`: the 200-finding fidelity sample (seed 20261021, seven strata across all five packages), the blank
  worksheet, the judge calibration report (planted-error catch rates) and the flag adjudication sheets. The human
  read of this sample is still open. Until it is done, scientific fidelity (does each finding state what its paper
  found) is unmeasured.
- `../benchmarks/`: the model-emitted identifier benchmark that led to v1.2 (every Tier 1-2 id looked up at its
  authority), with the v1.2 plan.
- `../releases/`: build records per release (summary, package index, tarball checksums, example README and
  LIMITATIONS, the label correction applied in v1.2).

Built with [condition-findings-builder](https://github.com/erinmagennis/condition-findings-builder). Index of the
project: [condition-findings](https://github.com/erinmagennis/condition-findings).
